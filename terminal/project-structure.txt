📍 パス移動の練習（projectフォルダ内）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

現在地: /Users/[username]/project

【1階層下へ移動】
$ cd src
→ /Users/[username]/project/src

【2階層下へ移動】
$ cd src/components
→ /Users/[username]/project/src/components

【1階層上へ移動】
$ cd ..
→ /Users/[username]/project/src

【2階層上へ移動】
$ cd ../..
→ /Users/[username]/project

【横移動（同じ階層の別フォルダ）】
現在地: /Users/[username]/project/src
$ cd ../public
→ /Users/[username]/project/public

【絶対パスで直接移動】
$ cd /Users/[username]/project/tests/unit
→ /Users/[username]/project/tests/unit

🔄 相対パスの計算方法
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

FROM: /Users/[username]/project/src/components
TO:   /Users/[username]/project/tests/unit

ステップ1: 共通の親を見つける → /Users/[username]/project
ステップ2: 現在地から親まで上る → ../.. (2階層上)
ステップ3: 親から目的地へ下る → tests/unit

答え: ../../tests/unit

Q1: /Users/[username]/project/public/images から
    /Users/[username]/project/src への相対パスは？
    答え: ../../src

Q2: /Users/[username]/project/src/styles から
    /Users/[username]/project/docs への相対パスは？
    答え: ../../docs

Q3: /Users/[username]/project/tests/unit から
    ホームディレクトリ(/Users/[username])への相対パスは？
    答え: ../../..

Q4: 現在地が /Users/[username]/project/src/components の時、
    logo.png ファイルへの相対パスは？
    答え: ../../public/images/logo.png
