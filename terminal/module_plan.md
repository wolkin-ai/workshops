# Terminal研修 モジュール構成案

## 1. 研修概要
- **目的**：非エンジニアがターミナル操作に自信を持ち、AI／API活用とGit実務にスムーズに接続できるようにする。
- **対象**：APIもGitも未経験のビジネスメンバー／社内AI開発者候補。
- **位置づけ**：API講座（概念理解）→ 本研修 → Git講座（詳細演習）という全体カリキュラムの中核。

## 2. 全体タイムライン（120分想定）
1. **オープニング：API×AIデモ**（10分）
2. **モジュールA：ターミナル基礎ハンズオン**（35分）
3. **モジュールB：CLIインストール体験**（20分）
4. **モジュールC：APIウォームアップ演習**（25分）
5. **モジュールD：Gitクイックラン**（20分）
6. **まとめ＆フォローアップ導線**（10分）

## 3. モジュール詳細

### 3.1 オープニング：API×AIデモ（講師デモ）
- **ねらい**：ターミナルからAIを操作できるワクワク感を先に提示し、学習意欲を引き出す。
- **進め方**：
  - `curl`でOpenAI ChatGPT API（`/v1/responses`）を叩き、シンプルなプロンプトとレスポンスをスクリーン投影。
  - リクエスト構造（エンドポイント／ヘッダー／JSONボディ）とレスポンス読み解きポイントを口頭で解説。
  - ターミナル型AI（Codex CLI等）がどのようにコマンド作業を支援するかをショートデモ。

### 3.2 モジュールA：ターミナル基礎ハンズオン
- **ゴール**：基本コマンドを「自分の手」で実行し、恐怖感をなくす。
- **内容**：
  - シェルとパスの考え方、ホームディレクトリと相対／絶対パスの確認。
  - コマンド演習：`pwd`、`ls`、`cd`、`mkdir`、`touch`、`cat`、リダイレクト（`>`／`>>`）、`mv`、`cp`、`history`、`cd ..`。
  - 演習課題：新規ディレクトリ作成→ファイル生成→内容追記→コピー／移動→履歴確認。
- **サポート**：コマンドチートシートとエラー時の対処フローを配布。

### 3.3 モジュールB：CLIインストール体験
- **ゴール**：CLIツール導入の一連の流れを理解し、社内外のツール導入を自走できる状態にする。
- **内容**：
  - Homebrewの有無確認→アップデート。
  - Salesforce CLIを`brew install salesforce-cli`で導入し、`sf --version`で確認。
  - 認証フロー（Webログインまたはトークン投入）のデモ、主要サブコマンドの紹介。
- **演習**：参加者自身の環境で導入→認証→情報取得（例：`sf org list`）。
- **ポイント**：パス設定やエラー時のリカバリ手順を共有し、CLI導入の共通知識を形成。

### 3.4 モジュールC：APIウォームアップ演習
- **ゴール**：APIの概念を体験的に理解し、ターミナルからのリクエスト実行に慣れる。
- **内容**：
  - OpenAI API利用時の注意点（APIキー管理、レート制限、コスト）。
  - `curl`リクエストを参加者が追体験し、リクエスト要素をシートに書き込んで整理。
  - レスポンスの読み方と、成果物（例：回答テキスト）を他モジュールで利用するアイデアを議論。
- **演習コマンド例**：

  ```bash
  curl https://api.openai.com/v1/responses \
    -H "Authorization: Bearer $OPENAI_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "model": "gpt-4.1-mini",
      "input": "Salesforce CLIの導入手順を3行で説明して"
    }'
  ```

- **フォロー**：キーを扱えない環境向けに、講師が代わりに実行しスクリーンで共有する代替手段も準備。

### 3.5 モジュールD：Gitクイックラン
- **ゴール**：ターミナル操作とGit操作のつながりを掴み、Git講座への橋渡しとする。
- **内容**：
  - `git --version`確認、ユーザー名／メール設定の振り返り。
  - `git clone`で教材リポジトリ取得→READMEの1行編集→`git status`確認。
  - `git add .`→`git commit`→`git push`までを一気通し。
- **支援**：作業チェックリスト・トラブルFAQ・Git講座案内を配布。

### 3.6 まとめ＆フォローアップ
- **振り返り**：各モジュールで得た学びをグループ共有。
- **次アクション**：
  - Slackチャンネルでの質問受付と演習課題提出（例：任意CLI導入報告、`curl`実行結果共有）。
  - Git講座の日程・事前準備のリマインド。
  - 実務応用アイデア（社内API×CLI×AIなど）の簡易ヒアリング。

## 4. 事前・事後タスク
- **事前**：PCの管理者権限確認、Homebrewインストール、OpenAI APIキー取得フローの周知。
- **事後**：アンケートで理解度と不安点を収集し、Git講座のカリキュラム調整に活用。

## 5. 必要リソース
- 演習用コード／リポジトリ：READMEと手順書、誤操作リカバリガイド。
- スライド：AI導入成熟度モデル、API基礎、CLI導入ステップ。
- サポート体制：講師1＋メンター2（受講者10名想定）を推奨。
