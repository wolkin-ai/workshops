# Terminal研修の背景

## 背景：AI導入成熟度モデル

2025年10月22日に実施されたW/IF AI勉強会の内容をもとに、この研修はAI導入成熟度のPhase 2（組織×汎用）からPhase 3（個人×特化）への移行を支援するために設計されています。

### AI導入成熟度の4象限モデル

1. **Phase 1（個人×汎用）**：ChatGPT・Geminiで文章作成・リサーチ活用
   - ゴール：AIに慣れる、抵抗感をなくす
   - 現状、多くの企業がこの段階にとどまっている

2. **Phase 2（組織×汎用）**：全社でAI活用推奨、組織でAIリテラシーを育む
   - ゴール：「AIを使うのが当たり前」な文化を作る
   - このフェーズから、AIにハマる人が現れ始める

3. **Phase 3（個人×特化）**：AIが楽しくなり、極める人が現れる
   - Cursor・Dify/n8n・GAS等の利用、実務自動化に取り組む
   - （エンジニア/Biz等かかわらず）社内AI開発者が誕生

4. **Phase 4（組織×特化）**：個人AI専門家が中心となりチームや仕組み構築
   - AIが社内コンテキストを理解して自律的に機能する
   - 技術・知識・文化が三位一体となり、持続可能なAI活用を実現

### 主要な課題：「技術深化の壁」（Phase 2 → 3）

Phase 2からPhase 3への移行には、エンジニアがよく使うツール/概念への理解が必要：

- **Git/ターミナル操作**：ソースコード管理とコマンドライン操作の基礎知識
- **API連携**：社内サービスとAIを標準インターフェースで接続
- **OAuth認証**：安全な接続と権限管理
- **MCP (Model Context Protocol)**：AIと外部データソース・ツールをシームレスに接続する標準プロトコル

## なぜTerminal研修が重要なのか

### 核心的な課題：コンテキストの自動化

- AIが真価を発揮するには、**自動的に社内コンテキストを理解する**必要がある
- 毎回手動で文脈を教えるのは非効率（人間もAIも）
- 理想の状態：AIが自動で社内情報にアクセスし、情報を理解し振る舞う

### 非エンジニアの技術理解の重要性

以下を実現するシステムを構築するために：
- Dify/n8nなどのワークフローツールで社内サービスに安全に接続
- バイブコーディングで社内システム構築
- セキュアな接続を維持

**エンジニアがよく使う作法の理解が必要**：
- ターミナル/コマンドライン操作
- Gitによるソースコード管理
- 認証の仕組み
- API連携のパターン

## 研修の目的

参加者が以下を達成できるようにする：

1. ターミナル操作への抵抗感をなくす
2. 基本的なコマンドライン概念を理解する
3. Phase 3のツール（Cursor、GAS、Dify/n8n）の基礎を構築する
4. AIが自律的に会社のコンテキストを活用できるシステム作りに進む

## 対象者

- 「社内AI開発者」を目指す非エンジニア
- 技術ツールを学ぶビジネスチームメンバー
- 「AIを使う」から「AIで作る」へ移行する全ての人

## 期待される成果

参加者は以下に必要な技術的基盤を獲得：

- 高度なAI開発ツール（Cursorなど）の使用
- ワークフロー自動化の実装
- 組織のコンテキストを理解するAIシステムの構築への貢献
- AI導入成熟度のPhase 2からPhase 3への進化

## 本質的な考え方

> 「AIを賢く」から「コンテキスト理解の仕組み作り」へ

毎回「あなたはプロのXXXです、これはこういう背景で...」と説明するのは人間もAIも非効率。**「自動でコンテキストを渡す」仕組みがカギ**。

この研修は、その仕組みを作るための第一歩となる技術的基礎を提供します。

## モジュール構成案

### 1. APIウォームアップ
- RESTとJSONの基本整理。
- `curl`でOpenAI ChatGPT API（`/v1/responses`）を叩き、プロンプト→レスポンスの流れを体験。
- リクエスト要素（エンドポイント・ヘッダー・ボディ）とレスポンスの読み方を理解する。

```bash
curl https://api.openai.com/v1/responses \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4.1-mini",
    "input": "ターミナル研修の学びを要約してください"
  }'
```

### 2. ターミナル基礎講座
- シェルとパスの考え方、`pwd`・`ls`・`cd`・`mkdir`・`touch`・`cat`・リダイレクトを習得。
- `mv`・`cp`・`history`・`cd ..`で戻る操作までカバーし、日常利用を想定した練習を実施。
- Git講座と連動し、ファイル生成→編集→状態確認の流れを練習。

### 3. CLIインストール体験
- Homebrew確認からSalesforce CLIインストール、ログイン設定までを演習。
- CLIで得た情報をChatGPTへの`curl`入力に再利用し、「コンテキスト自動化」の実感を促す。

### 4. ターミナル型AIとの連携
- Codex CLIなど対話型CLIエージェントを紹介し、ターミナル操作をAIと協働するデモを実施。
- 簡易スクリプトや社内CLIをAIに説明しながら改良する体験でPhase 3の働き方を疑似体験。

### 5. Git講座への接続
- `git clone`で教材リポジトリ取得→README編集→`git add .`→`git commit`→`git push`を体験。
- ターミナル操作との関連を明確にし、受講済み／未受講どちらにも響くリマインド資料とチェックリストを配布。

### 6. フォローアップ
- Slackでの質問受付と復習タスク（例：任意CLIのインストール報告、`curl`でのAPI活用ログ）を設定。
- 次講座（Git／自動化ツール）への橋渡しを明確化。
